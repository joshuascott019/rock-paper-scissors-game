# Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

The player chooses rock, paper, or scissors. The computer chooses its move, the game determines whether the round is a win, loss, or tie, and the score updates across rounds. The game also includes basic computer strategy that reacts when the player repeats the same choice.

## Features

- Rock, paper, and scissors choice buttons
- Computer choice generation
- Win/loss/tie detection
- Player and computer score tracking
- Reset button
- Basic repeated-choice pattern detection
- Image-based choice display using a sprite
- Responsive layout

## Project Files

- `index.html` - page structure and game interface
- `styles.css` - visual styling, layout, responsiveness, and sprite display
- `script.js` - game logic, scoring, DOM updates, and computer strategy
